# Codedock Operational Scripts

Canonical location for Codedock host lifecycle, maintenance, and backup operations.

## Scripts

- `backup.sh`: Creates full database and asset backups.
- `restore.sh`: Restores database and assets from backup archives safely.
- `upgrade.sh`: Upgrades Codedock control plane to latest version.
- `downgrade.sh`: Reverts Codedock control plane to previous version.
- `diagnostics.sh`: Runs system pre-flight diagnostics.
- `test-scripts.sh`: Automated test runner for operational scripts.
