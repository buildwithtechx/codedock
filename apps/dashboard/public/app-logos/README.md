# App catalogue logos

Brand SVGs for the one-click catalogue, bundled locally so self-hosted and offline dashboards render without a CDN. Each file is named after the template `icon:` key (`<icon>.svg`); `_generic.svg` is the fallback for apps without a brand mark.

Sources: [Simple Icons](https://simpleicons.org) (CC0). Brand marks belong to their respective owners and are used for identification only.
